# Circadian Display

## Mission

Create an open-source Android application that improves evening screen comfort through adaptive warmth and dimming curves.

Unlike existing blue-light filters that rely on static settings, Circadian Display continuously adjusts screen characteristics throughout the evening based on user-defined curves.

The project focuses on comfort, readability, and user control rather than analytics, tracking, or monetization.

## Core Philosophy

* Open source first
* Privacy first
* No accounts
* No cloud dependencies
* No advertisements
* User owns all data

## Primary Differentiator

Dynamic comfort curves.

Users define how screen warmth and dimming evolve through the evening instead of selecting a fixed temperature or intensity.

## Success Criteria

Version 1 is successful if:

* Users can define comfort curves
* Curves are applied automatically
* Native and overlay modes are supported
* Project is publicly released
* Documentation is complete
* Community contributions are possible
