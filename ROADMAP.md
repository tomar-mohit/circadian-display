# Roadmap

## Phase 0 - Foundation

Goal:
Project setup and architecture.

Deliverables:

* GitHub repository
* Documentation
* Android project skeleton
* CI pipeline
* Code style rules

Status:
Done

## Phase 1 - Curve Engine

Goal:
Create the core interpolation engine.

Features:

* CurvePoint model
* CurveProfile model
* Linear interpolation
* Unit tests

Success Criteria:
Given any time of day, the engine returns warmth and dimming values.

Status:
Done

Features:

* Background updates
* Manual refresh
* Preview mode

Success Criteria:
Display state updates automatically.

Status:
Done

Done
